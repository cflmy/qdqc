## 求道量子

**QDQC** 是 Quantum Dot Quantum Computing（量子点量子计算）的缩写。量子点量子计算和超导、光量子类似，是一种很有希望大规模化的实现方式。

尽管如此，求道量子并不打算成为量子点路线的坚定拥趸。考虑到量子计算仍处在 NISQ（含噪声中等规模量子）时代，本刊不打算、也绝不会只宣传一种技术路径——叠加、纠缠、线路、纠错与各家硬件，都会写；能核对、能复述，比站队更重要。

正因如此，我们将网站命名为求道量子。你也可以把它读作 Qode Quoc：Qode 源自 Quantum Code 的变体，承载代码与可执行知识的理念；Quoc 由缩写 QC 演化而来，读音与 Quark（夸克）相近。夸克作为物质的基本单元，恰好呼应本站求索量子本源的初心。有时也会笑称读作 code coze——中文里可解作「码扣」，正是 Marqdo 的中文名。

中国境内从事量子计算的企业不少，可相关内容仍常常零碎、不成体系，算不上好的发展生态。所以，求道者！不必感到迷茫——不管你对量子了解有多少，都再次诚挚地欢迎你。

## 关于 Marqdo

Marqdo 是求道量子使用的语言——这里的「使用」有多重含义。最直接的：你此刻看到的 [求道量子官网](https://qdqc.com)，就是用 Marqdo 搭起来的。

另一方面，Marqdo 还在不断完善量子计算相关的框架；未来它未尝不会成为量子计算的首选语言之一，因此本刊积极选用它，以免在浪潮里落伍。简略几条值得期待的特性（细节见 [Hello，Marqdo!](/post/hello-marqdo)、[Marqdo 官网](https://www.marqdo.com) 与 [GitHub](https://github.com/cflmy/marqdo)）：

1. **代码即文档**：源码后缀是 .mq.md，可被 Markdown 自然解析；借助 GFM 表格等语法，代码本身就好读。
2. **文档即知识库**：设计参考 Open Knowledge Format（OKF），依赖关系可生成 yaml，让知识本身成为可执行的体系——对大模型辅助写算法尤其有用。
3. **易于审计的公式**：公式可当作变量嵌入代码执行，写完跑一遍就能核对是否正确。
4. **高扩展、轻量 Jupyter**：外联扩展库可用围栏执行非 Marqdo 代码并查看输出，却比传统 notebook 更轻、更适合 git。
